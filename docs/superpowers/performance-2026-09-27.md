# 2026-09-27 构建测量

环境：Windows 11，仓库隔离 worktree 内的 Python 3.13 虚拟环境；未运行旧 `r.cmd` 或下载客户端可执行程序。旧 README 的“三分钟”来自不同环境和输入，不作为可比较基线。

离线固定输入：将新增两条来源后生成的六组 `fin.txt` 复制到 worktree 内临时 fixture，分别作为本组来源，同时复制现有 `del.ini`；`a1` 另外读取本轮 `a2/fin.txt`，`big-data` 另外读取本轮 `cdn/fin.txt`。不进行网络请求，也不发布文件。三次 `generate` 实际耗时为 36.943、38.015、37.152 秒，中位数 37.152 秒；另一次启用 `tracemalloc` 测得 Python 分配峰值 414.1 MiB。此峰值不含全部原生进程内存，启用追踪的那次不计入耗时中位数。加入新增来源之前的一次相似输入测得中位数 34.775 秒，但规则数量与 fixture 不同，不能视为严格前后对照。

真实 HTTPS 来源的完整生成与发布：加入新增来源前耗时 114 秒；加入后首次成功构建耗时 113 秒，后续两次成功构建的 36 个输出文件 SHA-256 全部相同（最后一次使用补强的响应长度校验）。另有一次响应中途截断和一次 TLS 握手失败，均未发布部分产物；这些失败样本不计入成功构建耗时。网络时延和上游更新会改变后续测量结果。
